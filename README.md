# FaceSense: Emotion-Aware Greeting System

Upload a short video and get a greeting matched to your detected facial emotion.

## Tech stack
- Python, OpenCV, DeepFace (CNN trained on FER2013)
- Streamlit for the web UI

## Run locally
pip install -r requirements.txt
streamlit run app.py

## Deploy
Deployed on Streamlit Community Cloud, connected to this GitHub repo.
